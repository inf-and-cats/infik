# Практика, огонёк и вопрос про класс

## 1. Приложение (GitHub)
Отдай своему Claude Code в VS Code файл `prompt-for-claude.md` вместе с этой папкой. Он применит `practice.patch` к твоей текущей версии или внесёт правки вручную.

## 2. Сервер (Google Apps Script)
1. В проекте Apps Script создай файл **Streak** и вставь в него `server/Streak.gs`.
2. В **Code.gs**, в `doPost`, сразу после строки с `verifyInitData_` (рядом со строкой лиги) добавь:
   ```js
   if (/^streak_/.test(req.action)) return json_(streak_(user, req));
   ```
3. В **Bot.gs**, в `botHandle_`, сразу после `var cq = u.callback_query;` добавь:
   ```js
   if (typeof streakCallback_ === 'function' && streakCallback_(cq)) return;   // «Не напоминать» (Streak.gs)
   ```
4. Выбери функцию **streakSetup** и нажми «Выполнить». Она создаст лист «Огонёк», строку «Напоминание про огонёк» на листе «Бот» и ежедневный запуск в 18:00 по Москве.
5. «Развертывание» → «Управление» → новая версия (иначе приложение не увидит новые действия).

## Как это работает
- Лист «Огонёк»: id, имя, серия, последний день занятий (по Москве), напоминать да/нет, класс, когда последний раз напоминали.
- В 18:00 бот пишет тем, у кого огонёк горел вчера, а сегодня ещё нет. В сообщении кнопка «🔥 Зажечь огонёк» (открывает приложение) и «Не напоминать».
- Текст напоминания меняется на листе «Бот» (строка «Напоминание про огонёк», `{серия}` заменится на «5 дней»). Написать туда «выкл» — напоминания остановятся.
- Кто заблокировал бота, тому ставится «нет», чтобы не слать каждый день впустую.
- Колонка «Класс» — ответы на вопрос «В каком ты классе?». По ней видно, кто к нам пришёл.
